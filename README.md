# ✈️ Airline Delay Analysis Dashboard | Power BI

An interactive Power BI dashboard designed to analyze airline flight operations, delays, cancellations, airport activity, and operational trends.

The project transforms airline flight data into an interactive four-page business intelligence dashboard to identify delay patterns, compare airline performance, analyze airport activity, and understand the major causes of flight delays.

---

## 📌 Project Overview

Airline delays can negatively impact passenger experience, operational efficiency, and airline performance. This project analyzes historical flight data to identify patterns in delays, cancellations, diversions, airport activity, and flight operations.

The dashboard provides a consolidated view of airline performance and enables users to explore operational trends through interactive visualizations, slicers, KPI cards, geographic analysis, and time-based analysis.

---

## 🎯 Problem Statement

The objective of this project is to analyze airline flight operations and identify the key factors contributing to delays and cancellations.

The dashboard addresses questions such as:

- Which airlines experience higher levels of flight delays?
- Which airports have greater flight activity and delay concentrations?
- What are the major causes of flight delays?
- How do delays vary across different months and days?
- How frequently are flights cancelled or diverted?
- How does flight volume relate to operational performance?
- Which areas require greater attention for improving operational efficiency?

## 📈 Key Performance Indicators

The dashboard tracks the following operational KPIs:

| KPI | Description |
|---|---|
| Total Flights | Overall number of flights analyzed |
| Total Airlines | Number of airlines represented in the dataset |
| Cancelled Flights | Total number of cancelled flights |
| Diverted Flights | Total number of diverted flights |
| Average Departure Delay | Average delay in departure time |
| Average Arrival Delay | Average delay in arrival time |
| Average Air Time | Average flight air time |
| Average Distance | Average flight distance |
| Total Delay Minutes | Total accumulated delay duration |
| Cancellation Rate | Percentage of flights that were cancelled |
